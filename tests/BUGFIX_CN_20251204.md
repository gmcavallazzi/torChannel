# Critical Bugfix: Crank-Nicolson Explicit Diffusion at Boundaries

**Date:** December 4, 2025
**Status:** FIXED ✅

---

## 🐛 Bug Description

The Crank-Nicolson implementation had **incorrect boundary formulas** for the explicit diffusion term in the u and v velocity components. This caused:
- ❌ Non-physical momentum changes
- ❌ Bulk velocity drift
- ❌ Eventual numerical instability (NaNs) in simulations

---

## 🔍 Root Cause

### **Incorrect Implementation (BROKEN)**

For u-component at **bottom boundary** (k=0), operators.py:662:
```python
# WRONG - Missing interior flux term
d2u = 2.0 * (u_interior[:, :, 1] - u_interior[:, :, 0]) / (dz_left[0] * dz_cell[0])
```

For u-component at **top boundary** (k=nz-1), operators.py:666:
```python
# WRONG - Missing interior flux term and incorrect structure
d2u = 2.0 * (u_interior[:, :, nz] - u_interior[:, :, nz+1]) / (dz_right[nz-1] * dz_cell[nz-1])
```

### **Why It's Wrong**

The second derivative should be computed as:
```
d²u/dz² = (flux_right - flux_left) / dz_cell
```

Both fluxes must be included:
1. **flux_left**: From ghost cell to current cell
2. **flux_right**: From current cell to next interior cell

The broken code only included the boundary flux, omitting the interior flux entirely!

---

## ✅ Correct Implementation (FIXED)

### **Bottom Boundary (k=0)**
```python
# Correct formula includes BOTH fluxes
# flux_right = (u[2]-u[1])/dz_right[0]
# flux_left = 2*u[1]/dz_left[0]  (using BC u[0]=-u[1])
d2u = ((u_interior[:, :, 2] - u_interior[:, :, 1]) / dz_right[0] -
       2.0 * u_interior[:, :, 1] / dz_left[0]) / dz_cell[0]
```

### **Top Boundary (k=nz-1)**
```python
# Correct formula includes BOTH fluxes
# flux_right = -2*u[nz]/dz_right[nz-1]  (using BC u[nz+1]=-u[nz])
# flux_left = (u[nz]-u[nz-1])/dz_left[nz-1]
d2u = (-2.0 * u_interior[:, :, nz] / dz_right[nz-1] -
       (u_interior[:, :, nz] - u_interior[:, :, nz-1]) / dz_left[nz-1]) / dz_cell[nz-1]
```

Same fix applied to v-component (operators.py:742-753).

## 📝 Technical Details

### **The Second Derivative Stencil**

On a non-uniform grid with no-slip BC (u[0] = -u[1]):

```
Bottom boundary (k=0, first interior cell):
  d²u/dz²[0] = [(u[2]-u[1])/Δz_right - (u[1]-u[0])/Δz_left] / Δz_cell
             = [(u[2]-u[1])/Δz_right - 2*u[1]/Δz_left] / Δz_cell
                         ↑                    ↑
                   interior flux      boundary flux (with BC applied)
```

```
Top boundary (k=nz-1, last interior cell):
  d²u/dz²[nz-1] = [(u[nz+1]-u[nz])/Δz_right - (u[nz]-u[nz-1])/Δz_left] / Δz_cell
                = [-2*u[nz]/Δz_right - (u[nz]-u[nz-1])/Δz_left] / Δz_cell
                        ↑                        ↑
                 boundary flux (with BC)   interior flux
```

## ⚠️ Impact on Previous Results

**Any simulations run with the broken CN implementation (before this fix) should be re-run.**

- Incorrect momentum dissipation at boundaries
- Spurious bulk velocity changes
- Eventual numerical instability

---

## 🎓 Lesson Learned

When implementing numerical schemes with:
1. Non-uniform grids
2. Boundary conditions embedded in stencils
3. Implicit-explicit splitting (IMEX)

**Always verify boundary stencils match interior stencil structure**, including:
- All flux contributions (not just boundary)
- Correct sign and magnitude of BC modifications
- Consistency with reference implementations (e.g., w-component)
