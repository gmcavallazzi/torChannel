# Numerical Methods and Accuracy Analysis

## Executive Summary

The codebase implements a **Direct Numerical Simulation (DNS)** solver for incompressible channel flow. The numerical schemes used are consistent with standard high-fidelity turbulence simulations.

| Discretization Component | Method | Order of Accuracy |
| :--- | :--- | :--- |
| **Time Integration** | Adams-Bashforth 2 (AB2) / Crank-Nicolson (CN) | **2nd Order** ($O(\Delta t^2)$) |
| **Spatial (Streamwise $x$, Spanwise $y$)** | Central Finite Difference (Uniform Grid) | **2nd Order** ($O(\Delta x^2, \Delta y^2)$) |
| **Spatial (Wall-normal $z$)** | Finite Difference on Stretched Grid | **Effectively 2nd Order** ($O(\Delta z^2)$) |

---

## Detailed Analysis

### 1. Time Discretization

The solver supports two primary time-stepping schemes, both providing 2nd-order accuracy.

#### **Explicit Scheme (AB2)**
- **Method**: Adams-Bashforth 2nd order.
- **Formulation**:
  $$ u^{n+1} = u^n + \Delta t \left( \frac{3}{2} \text{RHS}^n - \frac{1}{2} \text{RHS}^{n-1} \right) $$
- **Accuracy**: This is a multi-step method with a global truncation error of **$O(\Delta t^2)$**.

#### **Implicit-Explicit Scheme (IMEX)**
- **Method**: Mixed AB2 for explicit terms and Crank-Nicolson for implicit terms.
- **Implementation**:
    - **Explicit Terms**: Advection and horizontal diffusion ($x, y$) are treated with **AB2**.
    - **Implicit Terms**: Vertical diffusion ($z$) is treated with the **Theta-method** (default $\theta=0.5$, i.e., Crank-Nicolson).
- **Accuracy**: Since both AB2 and Crank-Nicolson are 2nd-order accurate, the combined IMEX scheme retains **$O(\Delta t^2)$** accuracy. This scheme is preferred for wall-bounded flows to overcome the severe viscous stability restriction ($\Delta t \sim \Delta z^2$) near the walls.

#### **Pressure Projection**
The solver uses a standard fractional-step (projection) method:
1.  **Prediction**: Compute intermediate velocity $u^*$ (ignoring pressure).
2.  **Poisson Solve**: Solve $\nabla^2 p = \frac{\nabla \cdot u^*}{\Delta t}$ to enforce continuity.
3.  **Correction**: Update velocity $u^{n+1} = u^* - \Delta t \nabla p$.

While classical splitting errors can sometimes be $O(\Delta t)$ for pressure at boundaries, the velocity field—which is the primary quantity of interest in DNS—maintains **2nd-order accuracy**.

### 2. Spatial Discretization

The code uses a **Staggered Grid (Arakawa C-grid)** arrangement:
- **Pressure ($p$)**: Stored at cell centers.
- **Velocity ($u, v, w$)**: Stored at their respective cell faces.

#### **Horizontal Directions ($x, y$)**
- **Grid**: Uniform spacing ($\Delta x = L_x/N_x$, $\Delta y = L_y/N_y$).
- **Method**: Standard Central Finite Differences.
- **Approximation**:
  $$ \frac{\partial^2 u}{\partial x^2} \approx \frac{u_{i+1} - 2u_i + u_{i-1}}{\Delta x^2} $$
- **Accuracy**: strictly **2nd Order ($O(\Delta x^2)$)**.

#### **Wall-Normal Direction ($z$)**
- **Grid**: Non-uniform (stretched) grid generated via a hyperbolic tangent mapping (verified in `utils.py`). This clusters points near the walls to resolve the boundary layer.
- **Method**: Finite Volume / Finite Difference on a non-uniform grid.
- **Approximation**:
  The diffusion operator is discretized as:
  $$ \frac{\partial^2 u}{\partial z^2} \approx \frac{1}{\Delta z_{cell}} \left( \frac{u_{k+1}-u_k}{\Delta z_{right}} - \frac{u_k-u_{k-1}}{\Delta z_{left}} \right) $$
- **Accuracy Nuance**:
    - On a *randomly* spaced grid, this discretization is formally only **1st order accurate ($O(\Delta z)$)** because the leading truncation error terms do not cancel perfectly (due to $\Delta z_{right} \neq \Delta z_{left}$).
    - **Supraconvergence**: However, when the grid is generated by a **smooth mapping function** (like the `tanh` function used here), the variation in grid spacing is smooth ($\Delta z_{k+1} = \Delta z_k + O(\Delta z^2)$). Under these specific conditions, the 1st-order error terms become higher order, and the method recovers **global 2nd-order accuracy ($O(\Delta z^2)$)**.

### Conclusion
The code constitutes a robust **2nd-order accurate** solver in both time and space. This level of accuracy is the standard requirement for Direct Numerical Simulations to correctly resolve the turbulent energy cascade and wall-shear stresses.
